# casaemjacuipe

Fotos e vídeos dos posts do Instagram [@casaemjacuipe](https://www.instagram.com/casaemjacuipe/): casa com piscina pra até 20 pessoas no condomínio Parque do Jacuípe, em Barra do Jacuípe (BA).

Os arquivos ficam públicos aqui só para o agendador (Metricool) conseguir baixar e publicar cada post no horário marcado.

- `dezembro/`: pacote de 23/11 a 16/12/2026, com os reels (R01 a R11) e os stories (S01 a S09).
